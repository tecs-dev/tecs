# Dependencies

Vendor pure-Lua libraries with LuaRocks. The project tree already uses the
LuaRocks layout, so a plain `--tree` install puts modules exactly where the
game and the type checker look:

```sh
luarocks install --tree src/vendor --lua-version=5.1 inspect
luarocks install --tree src/vendor --lua-version=5.1 inspect-tl-type
```

Teal declarations for popular rocks are published as `<rock>-tl-type`
packages; install the matching one so `tecs check` keeps type-checking code
that requires the rock.

Two constraints to know:

- Only pure-Lua rocks work. The game runtime is LÖVE's LuaJIT with no C
  toolchain, and `tecs build` prunes LuaRocks bookkeeping (`bin/`,
  `lib/luarocks/`) from the shipped game.
- `src/vendor/` is regenerated by the CLI and gitignored in generated
  projects, so record installed rocks somewhere repeatable, such as a
  Makefile target, and reinstall after a fresh clone.
