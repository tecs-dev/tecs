# JetBrains Mono

`JetBrainsMono-ExtraBold.ttf` is JetBrains Mono ExtraBold 2.304.
`../bench/sprites.png` is the former printable-ASCII atlas retained only as a
multi-frame sprite benchmark fixture; the text renderer does not read it.
