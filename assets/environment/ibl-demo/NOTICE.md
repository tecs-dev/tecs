# IBL demo environment

The six SVG environment faces in this directory were created for the Tecs
project. Michael Dowling dedicates them to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

They are deliberately small, stylized test assets. Their broad color fields
and bright positive-Z sun make reflection direction, skybox orientation, and
roughness-selected mip filtering easy to inspect.
