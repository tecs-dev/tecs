# Tecs Particles Example

A simple example demonstrating the ParticleEmitter component in tecs.gfx.

## Features

- Procedurally generated particle texture
- Moveable particle emitter using arrow keys
- Demonstrates ParticleEmitter component with Love2D ParticleSystem
- Custom culling logic for particle rendering

## Running the Example

From the tecs project root:

```bash
make particles-example
```

Or run directly:

```bash
./examples/particles/run.sh
```

## Controls

- **Arrow Keys**: Move the particle emitter
- **ESC**: Quit

## What It Demonstrates

- Creating particle images programmatically with Love2D
- Configuring Love2D ParticleSystem parameters
- Using the ParticleEmitter component
- Moving entities with Transform component
- Camera following an entity
